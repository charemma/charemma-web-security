# Site Registry: security.charemma.de

This file is the site registry of the site folder `sites/security/` per the Sites section of `AGENTS.md`. The Structure and Discipline of the File Registry section of `AGENTS.md` apply to it.

## Site Intent

This site is security.charemma.de, the website for Charalambos Emmanouilidis' penetration testing services with a focus on Linux infrastructure. It presents the services, the engagement approach as an animated walkthrough, and a knowledge section on AI security, as static pages in German, English and Greek. The visual design in `sites/security/docs/design/` is the input the site's specification was derived from.
